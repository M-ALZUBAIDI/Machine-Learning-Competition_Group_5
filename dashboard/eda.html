CHAPTER 01 / 04 EXPLORATORY DATA ANALYSIS

What the raw catalog actually looks like.

90,836 near-Earth objects from NASA's NEO catalog, examined before any model saw them — class balance, feature distributions, and what separates a hazardous object from a routine one.

Dataset Overview

SOURCE: NASA NEO CATALOG (KAGGLE)
TOTAL RECORDS 90,836

id and name were dropped — they uniquely identify each object and carry no predictive signal. orbiting_body and sentry_object were dropped for near-zero variance (nearly every record shares one value). That leaves 5 numeric features: diameter (min/max), relative velocity, miss distance, and absolute magnitude.

Class Balance

TARGET: hazardous
81,996
NOT HAZARDOUS · 90.3%
8,840
HAZARDOUS · 9.7%

A severe class imbalance — roughly 9 non-hazardous objects for every 1 hazardous one. Left untreated, a model could score ~90% accuracy by predicting "not hazardous" every time while missing nearly all real threats. This is why SMOTE was applied to the training split only, synthesizing minority-class samples so the model actually learns what separates the two classes rather than just learning the imbalance.

Wide spreads across the board — diameter alone ranges from 0.0006 km to nearly 85 km, a scale difference of five orders of magnitude. This is exactly why StandardScaler was applied before training: without it, features with naturally larger numeric ranges (like miss_distance in raw km) would dominate distance-sensitive models regardless of their actual predictive value.

What Separates Hazardous From Safe

FROM VIOLIN / PAIR PLOTS

Hazardous objects cluster at absolute_magnitude under ~22 — meaning brighter, and therefore larger, objects. Size turns out to be the primary signal, with velocity and miss distance acting as secondary, supporting features rather than the main driver. This lines up with orbital mechanics intuition: a bigger object at a given distance simply poses more potential risk, which is exactly what the feature importance results (see Model Results) confirm numerically.
