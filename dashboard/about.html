HOW IT'S BUILT

System architecture & the team behind it.

Five pieces working together — training, model serving, live data, and the dashboard you're looking at right now.

Architecture

Training happens once, offline, in Colab. GitHub holds the result and feeds two independent deployments: Render runs the prediction API, Vercel runs this dashboard. The dashboard never touches the model directly — it calls Render over plain HTTP, the same way any outside app would, which is what proves the API genuinely works on its own.
