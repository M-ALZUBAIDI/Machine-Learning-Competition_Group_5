HOW IT'S BUILT

System architecture & the team behind it.

Five pieces working together — training, model serving, live data, and the dashboard you're looking at right now.

Architecture

GITHUB · RENDER · VERCEL · JPL

Training happens once, offline, in Colab. From there, GitHub is the single source of truth that both Render (the prediction API) and Vercel (this dashboard) deploy from independently. At runtime, the dashboard never talks to the model directly — it calls Render over HTTP, exactly like any external client would, which is what proves the API genuinely works standalone.
