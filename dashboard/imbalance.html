CHAPTER 02 / 04 THE IMBALANCE PROBLEM

90% of asteroids are harmless. That's exactly the trap.

A model that learns nothing can still look excellent on paper here — which is precisely why this step couldn't be skipped.

The Trap

RAW TRAINING SPLIT

Of 90,836 objects, only 8,840 (9.7%) are hazardous. A model that always predicts "not hazardous" — never looking at a single feature — would score roughly 90% accuracy on this dataset. It would also be completely useless: it would miss every real hazardous object, which for a hazard-detection system is the one failure mode that actually matters.

Accuracy alone is a misleading metric on imbalanced data. This is why the model comparison on the Results page also reports precision, recall, and F1 — recall on the hazardous class specifically is what tells us whether the model is actually doing its job.

SMOTE (Synthetic Minority Oversampling Technique) was applied to bring the two classes to parity — not by duplicating existing hazardous samples, but by generating new synthetic ones interpolated between real hazardous objects and their nearest neighbors in feature space. This teaches the model the actual shape of the minority class, rather than just repeating a handful of examples until it memorizes them.

The One Rule That Matters Here

NO DATA LEAKAGE
TRAIN SET BALANCED SMOTE applied
TEST SET UNTOUCHED real-world distribution

We only balanced the training data. The test set was left exactly as-is — real, imbalanced, untouched — so every result on the Results page reflects genuine performance, not an inflated score from testing on artificial data.
